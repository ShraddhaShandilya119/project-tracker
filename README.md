# 🚀 Project Tracker

A feature-rich Project Tracker application with multiple views (Kanban, List, Timeline), built using React, TypeScript, Zustand, and Tailwind CSS.

## 🔧 Features
- Kanban Board with drag-and-drop functionality  
- List View with sorting (Title, Priority, Due Date)  
- Virtual Scrolling for performance optimization  
- Filtering by Status and Priority  
- URL synchronization for persistent filters  
- Timeline (Gantt-style) view for task visualization  

## 🛠️ Tech Stack
- React (TypeScript)  
- Zustand  
- Tailwind CSS  
- Vite
